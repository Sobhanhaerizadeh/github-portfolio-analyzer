# 🔍 GitHub Portfolio Analyzer

Echtzeit-Analyse von GitHub-Profilen mit Darstellung von Repositories, Follower-Statistiken und Programmiersprachen als Diagramm.

---

## 📸 Preview

> Gib einen GitHub-Benutzernamen ein und erhalte sofort ein vollständiges Profil-Dashboard.


---

## ✨ Features

- 🔎 GitHub-Profil suchen mit einem Benutzernamen
- 📊 Zeigt ein Diagramm mit den meist genutzten Programmiersprachen
- 🏆 Top 6 Repositories nach Stars sortiert
- 👤 Profilinformationen: Avatar, Bio, Follower, Following, Repos
- ⚠️ Fehlerbehandlung: 404, API-Limit, leere Eingabe
- ⌨️ Enter-Taste als Shortcut unterstützt

---

## 🛠️ Technologien


- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- GitHub REST API
- Chart.js

---

## 🚀 Installation

```bash
# Repository klonen
git clone https://github.com/Sobhanhaerizadeh/github-portfolio-analyzer.git

# Ordner öffnen
cd github-portfolio-analyzer

# index.html im Browser öffnen (z.B. mit Live Server in VS Code)
```

> Kein Build-Tool, kein npm, kein Backend nötig. Einfach öffnen und fertig.
